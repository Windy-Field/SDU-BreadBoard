# 芯片合集实现说明

新增型号依据《数字电子技术实验常用芯片合集(1).docx》的逐脚表与引脚图建立，原有 74LS273、74LS283、74LS86、74LS00、74LS08、74LS32、74LS04 保持原实现

| 新增芯片 | 主要行为 |
| --- | --- |
| 74LS03 | OC 与非输出，下拉或释放节点，可与其他 OC 输出并接 |
| 74LS20 | 双四输入与非门，3、11 脚为 NC |
| CD4011 | 四路 CMOS 与非门，使用文档中的独立引脚排列 |
| 74LS125 | 低有效使能，关闭时输出高阻态 Z |
| 74LS138、74LS139 | 地址译码，选中输出为低，其余为高 |
| 74LS151、74LS153 | 地址选择数据，禁止时输出低；151 提供互补输出 |
| 74LS85 | 四位比较，支持级联输入 |
| 74LS48 | 高有效七段输出，灯测试、灭灯、灭零与 RBO 下拉 |
| 74LS74 | 上升沿 D 触发器，低有效异步置位和清零 |
| 74LS112 | 下降沿 JK 触发器，低有效异步置位和清零 |
| CD4027 | 上升沿 JK 触发器，高有效异步置位和清零 |
| 74LS160、74LS161 | 异步清零、同步装载、使能计数和进位输出 |
| 74LS194 | 保持、左右移位、并行装载和异步清零 |

## 引脚核对

新增芯片的引脚名逐一与文档提取的独立表 `tests/fixtures/chip-reference.json` 比较，图片位于 `assets/pinouts/document/`，原有芯片资料仍位于原厂图目录

74LS194 按提供文档的脚号实现：2 脚为 CP，3 脚为 SR，9/10 脚为 S0/S1，12～15 脚为 QA～QD。你使用实物芯片时，请继续核对具体厂家和型号的数据手册

## 验证范围

测试包括组合芯片全部有效输入、比较器级联、七段数字 0～9 与控制端优先级、两路触发器有效边沿和异步控制、计数器装载和循环、移位模式，以及真实面包板节点上的传播

未上电的芯片不驱动节点；关闭的三态缓冲器和释放的 OC 输出不与其他驱动冲突。弱上拉只在没有低电平驱动时将节点拉高

74LS48 的 BI/RBO 是双向端口，建议添加弱上拉后再测试灭零链。数字逻辑模型保留 X 未知与 Z 高阻，不模拟模拟电压、建立保持时间或器件损坏
