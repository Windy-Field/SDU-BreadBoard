# 芯片合集实现说明

新增型号的引脚和功能来自《数字电子技术实验常用芯片合集(1).docx》中的引脚表和引脚图，原先七种型号的脚号保持原样。v1.3.3 对照原厂资料复查了当时的 23 种芯片。测试范围和脚号差异详见[芯片核查报告](chip-audit.md)。

加入第三次实验所用的 6116 和 74LS244 之后，器件库共有 25 种芯片。这两种芯片的脚号和配图取自课件第 6、7 页。74LS138 沿用原有的三线八线译码模型，输出低电平有效。

| 新增芯片 | 主要行为 |
| --- | --- |
| 6116 | 完整 2048×8 异步 RAM，低有效片选、读允许和写允许，八位双向三态数据端口 |
| 74LS244 | 两组独立的四路同相三态缓冲器，1、19 脚分别低有效使能 |
| 74LS03 | OC 与非输出，下拉或释放节点，可与其他 OC 输出并接 |
| 74LS20 | 双四输入与非门，3、11 脚为 NC |
| CD4011 | 四路 CMOS 与非门，使用文档中的独立引脚排列 |
| 74LS125 | 低有效使能，关闭时输出高阻态 Z |
| 74LS138、74LS139 | 地址译码，选中输出为低，其余为高 |
| 74LS151、74LS153 | 地址选择数据，禁止时输出低；151 提供互补输出 |
| 74LS85 | 四位比较，支持级联输入 |
| 74LS48 | 高有效七段输出，0～15 字形、灯测试、灭灯、灭零、RBO 下拉与内部弱上拉 |
| 74LS74 | 上升沿 D 触发器，低有效异步置位和清零 |
| 74LS112 | 下降沿 JK 触发器，低有效异步置位和清零 |
| CD4027 | 上升沿 JK 触发器，高有效异步置位和清零 |
| 74LS160、74LS161 | 异步清零、同步装载、使能计数和进位输出 |
| 74LS194 | 保持、左右移位、并行装载和异步清零 |

## 引脚核对

测试将新增芯片的每个引脚名与文档提取的独立表 `tests/fixtures/chip-reference.json` 逐一作了比较。对应图片保存在 `assets/pinouts/document/`，原有芯片资料保留在原厂图目录

实验四使用的 74LS194 为标准 DIP-16。CP 为 11 脚，SR 为 2 脚，SL 为 7 脚，A～D 为 3～6 脚，QA～QD 为 15～12 脚。器件库提供 TI 顶视图和数据手册

74LS20 的材料版第 1 门输入为 1、2、12、13 脚；TI 标准 DIP 第 1 门输入为 1、2、4、5 脚。器件资料列出了这两组脚号

逐脚核对还发现了两处差异：74LS85 的材料版 A2/B2 使用 14/13 脚，TI 标准 DIP 使用 13/14 脚；74LS112 的材料版第二路 Q/Q′ 使用 7/9 脚，TI 标准 DIP 使用 9/7 脚。程序也保留了这两种芯片的材料版映射，并显示了差异提示

## 验证范围

测试覆盖了组合芯片有效输入、比较器级联、七段数字 0～15 与控制端优先级、两路触发器有效边沿和异步控制、计数器全部初值与装载模式、非 BCD 状态恢复、双向移位模式，以及真实面包板节点上的传播

芯片断电后会释放输出节点，三态缓冲器关闭时和 OC 输出释放时也处于高阻态。弱上拉会在没有低电平驱动时将节点拉高

6116 不限于课件简化接线中的低四位地址，A0～A10 全部参与片内寻址。CE′=0、WE′=0 时持续写入，OE′不影响写入；CE′=0、WE′=1、OE′=0 时读取。未选中、读禁止或写入时，RAM 都不驱动数据总线。数据脚没有内部上拉，悬空写入记为未知值，不会默认为 0。未知地址或写控制可能影响的单元也按未知值处理

RAM 内容属于易失运行状态，保存和导出只记录接线与开关，不记录 RAM 内容。断电、重新加载或重建运行状态后，内容未知，需要重新写入。操作时先结束写入，再让 74LS244 退出总线，再开启 RAM 读取，防止误写与驱动冲突

新增回归覆盖 6116 全部 2048 个地址、74LS244 全部数据与分组使能、74LS138 选通两片 RAM、课件四组读写数据、高位地址、错误隔离顺序、双驱动冲突、断电、存档恢复及双向数据脚的逻辑图布局

74LS48 的 BI/RBO 是双向端口，开路时内部弱上拉保持高电平，外部低电平可以控制灭灯。模型用 X 和 Z 表示未知与高阻状态，模拟电压、建立保持时间和器件损坏属于实物实验的观察范围
