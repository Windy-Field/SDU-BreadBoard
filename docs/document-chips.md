# 芯片合集实现说明

项目依据《数字电子技术实验常用芯片合集(1).docx》的逐脚表与引脚图实现了新增型号，原有七种型号沿用了原来的物理脚号。v1.3.3 对照原厂资料复查了全部 23 种芯片，具体测试与差异见[芯片核查报告](chip-audit.md)

| 新增芯片 | 主要行为 |
| --- | --- |
| 74LS03 | OC 与非输出，下拉或释放节点，可与其他 OC 输出并接 |
| 74LS20 | 双四输入与非门，3、11 脚为 NC |
| CD4011 | 四路 CMOS 与非门，使用文档中的独立引脚排列 |
| 74LS125 | 低有效使能，关闭时输出高阻态 Z |
| 74LS138、74LS139 | 地址译码，选中输出为低，其余为高 |
| 74LS151、74LS153 | 地址选择数据，禁止时输出低；151 提供互补输出 |
| 74LS85 | 四位比较，支持级联输入 |
| 74LS48 | 高有效七段输出，0～15 字形、灯测试、灭灯、灭零、RBO 下拉与内部弱上拉 |
| 74LS74 | 上升沿 D 触发器，低有效异步置位和清零 |
| 74LS112 | 下降沿 JK 触发器，低有效异步置位和清零 |
| CD4027 | 上升沿 JK 触发器，高有效异步置位和清零 |
| 74LS160、74LS161 | 异步清零、同步装载、使能计数和进位输出 |
| 74LS194 | 保持、左右移位、并行装载和异步清零 |

## 引脚核对

测试将新增芯片的每个引脚名与文档提取的独立表 `tests/fixtures/chip-reference.json` 逐一作了比较。对应图片保存在 `assets/pinouts/document/`，原有芯片资料保留在原厂图目录

74LS194 采用了提供文档中的脚号：2 脚为 CP，3 脚为 SR，9/10 脚为 S0/S1，12～15 脚为 QA～QD。你连接实物芯片时，请按具体厂家和型号的数据手册核对

74LS20 的材料版第 1 门输入为 1、2、12、13 脚；TI 标准 DIP 第 1 门输入为 1、2、4、5 脚。74LS194 的材料版也与 TI 标准 DIP 脚号不同。程序保留了材料版接法，并在这两种芯片的资料面板前部列出了差异，方便你对照接线

逐脚核对还发现了两处差异：74LS85 的材料版 A2/B2 使用 14/13 脚，TI 标准 DIP 使用 13/14 脚；74LS112 的材料版第二路 Q/Q′ 使用 7/9 脚，TI 标准 DIP 使用 9/7 脚。程序也保留了这两种芯片的材料版映射，并显示了差异提示

## 验证范围

测试覆盖了组合芯片有效输入、比较器级联、七段数字 0～15 与控制端优先级、两路触发器有效边沿和异步控制、计数器全部初值与装载模式、非 BCD 状态恢复、双向移位模式，以及真实面包板节点上的传播

芯片断电后会释放输出节点，三态缓冲器关闭时和 OC 输出释放时也处于高阻态。弱上拉会在没有低电平驱动时将节点拉高

74LS48 的 BI/RBO 是双向端口，开路时内部弱上拉保持高电平，外部低电平可以控制灭灯。模型用 X 和 Z 表示未知与高阻状态，模拟电压、建立保持时间和器件损坏属于实物实验的观察范围
