## 引脚核对

新增芯片的引脚名逐一与文档提取的独立表 `tests/fixtures/chip-reference.json` 比较，图片位于 `assets/pinouts/document/`，原有芯片资料仍位于原厂图目录

74LS194 按提供文档的脚号实现：2 脚为 CP，3 脚为 SR，9/10 脚为 S0/S1，12～15 脚为 QA～QD。你使用实物芯片时，请继续核对具体厂家和型号的数据手册

74LS20 的材料版第 1 门输入为 1、2、12、13 脚；TI 标准 DIP 第 1 门输入为 1、2、4、5 脚。74LS194 的材料版也与 TI 标准 DIP 脚号不同。程序保留材料版接法，并在这两种芯片的资料面板前部显示差异，避免混用

进一步逐脚核对发现，74LS85 的材料版 A2/B2 使用 14/13 脚，TI 标准 DIP 使用 13/14 脚；74LS112 的材料版第二路 Q/Q′ 使用 7/9 脚，TI 标准 DIP 使用 9/7 脚。这两种也保留材料版映射，并显示差异提示

## 验证范围

测试包括组合芯片有效输入、比较器级联、七段数字 0～15 与控制端优先级、两路触发器有效边沿和异步控制、计数器全部初值与装载模式、非 BCD 状态恢复、双向移位模式，以及真实面包板节点上的传播

未上电的芯片不驱动节点；关闭的三态缓冲器和释放的 OC 输出不与其他驱动冲突。弱上拉只在没有低电平驱动时将节点拉高

74LS48 的 BI/RBO 是双向端口，开路时内部弱上拉保持高电平，外部低电平可以控制灭灯。数字逻辑模型保留 X 未知与 Z 高阻，不模拟模拟电压、建立保持时间或器件损坏
