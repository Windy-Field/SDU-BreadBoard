# RAM 字扩展操作

## 开关

| 端口 | 用途 |
| --- | --- |
| K7～K0 | 写入数据，高位在左 |
| K11～K8 | 片内地址，高位在左 |
| K12 | 0选第一片，1选第二片 |
| K13 | 0写入，1停止写入 |
| K14 | 0读出，1关闭读出 |
| K15 | 0接入数据开关，1隔离数据开关 |
| L7～L0 | 读出结果 |

## 写入

1. 打开电源，将K13、K14、K15都设为1
2. 设置K12选片、K11～K8地址、K7～K0数据
3. K15设为0，接入数据
4. K13设为0，再设回1，完成写入
5. K15设回1，隔离数据

重复步骤2～5，先写完下面四组数据

## 验收数据

| K12 | K11～K8 | K7～K0 |
| --- | --- | --- |
| 0 | 1010 | 01010101 |
| 0 | 0101 | 10101010 |
| 1 | 1010 | 11111111 |
| 1 | 0101 | 00000000 |

## 读取

保持K13=1、K15=1，把K14设为0。只切换K12和K11～K8，检查L7～L0是否与表中数据一致

再次写入前，先把K14设回1。不需要使用P+或P−

## 提醒

先停止写入，再隔离数据。Z表示总线未输出，未写入的地址读出X。断电、刷新或切换实验后需重新写入，保存存档不保存RAM数据

## 芯片位置

芯片均缺口朝左，跨接E/F沟槽。板块从上到下编号1～4
