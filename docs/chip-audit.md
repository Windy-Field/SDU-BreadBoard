# 芯片核查报告

## 结论

本次核查覆盖当前器件库的 23 种芯片。核心数字逻辑已按下表验证，发现的逻辑错误已在 v1.3.3 修正；74LS20、74LS85、74LS112、74LS194 保留材料版脚号，与 TI 标准 DIP 封装的差异会在资料面板显示

这份报告区分三件事：芯片的数字逻辑行为、脚号来源，以及模拟器没有计算的电气和时间特性。通过数字逻辑测试不等于完成了模拟电路或实物器件的全部验证

## 已修复

| 项目 | 原问题 | 修正与验证 |
| --- | --- | --- |
| 74LS48 字形 | 数字 6、9 使用了另一种七段字体 | 按 TI LS48 的 T2 表改为 6 不亮 a 段、9 不亮 d 段，核对全部 16 种字形和 128 种控制组合 |
| 74LS48 输出结构 | 段输出按推挽处理，BI/RBO 开路时未使用内部弱上拉 | 高段由内部弱上拉提供，低段下拉；供电时 BI/RBO 开路为高，芯片断电时不驱动，外部灭灯与级联灭零均可恢复 |
| 74LS160 | 并行装入 10～15 后按普通二进制递增 | 按原厂状态图恢复：10→11→4，12→13→4，14→15→0；这些非法 BCD 状态不产生 RCO |
| 74LS112、CD4027 | 上电未知状态下，明确的 J/K 置位或复位仍得到 X | 有效边沿下 J=1、K=0 得 1，J=0、K=1 得 0，不依赖旧值是否已知 |
| 时序保持 | 时钟未知时，即使计数禁止或移位保持也会抹掉已知状态 | 明确禁止计数或保持移位时保留原值；结果无法确定时仍使用 X |
| 74LS283 | 部分已经能确定的进位被未知输入扩大为 X | 进位使用三项多数逻辑，不影响二值加法结果 |
| 74LS85 | 高位已能判定大小时，低位未知仍让全部输出变为 X | 从最高位向下比较，已确定的高位关系不依赖低位 |
| 引脚类型与诊断 | NC 在资料表中显示为输入，双向脚显示为单纯输出 | 分别标为 NC 与输入/输出；异步置位和清零同时有效时增加警告 |

## 模型边界

- 电源按逻辑高低处理，没有计算 TTL/CMOS 门限、负载电流、扇出、功耗或电阻值，因此不能用于判断器件能否直接驱动某个实际负载
- CMOS 器件在本板上按 5V 数字逻辑工作，没有模拟不同供电电压下的行为
- 时钟采用离散边沿，没有模拟传播延迟、毛刺、按键抖动、建立保持时间、亚稳态或模拟振荡
- X 表示模型无法确定，Z 表示没有驱动；未知控制组合按保守方式传播，不保证所有未知组合都能推导出最精确的部分已知结果
- 异步置位和清零同时有效时按资料表显示双高并给出警告，同时释放后的状态不能当作确定数据使用
- 74LS48 的内部上拉仅表示弱驱动优先级，没有模拟真实的 2kΩ 电阻与电流
