# 版本记录

## 版本规则

小改动增加补丁号，例如 1.0.0 → 1.0.1；大改动增加次版本号，例如 1.0.1 → 1.1.0；大规模重构增加主版本号，例如 1.1.0 → 2.0.0。版本号以 `src/version.mjs` 和 `package.json` 为准

## v1.2.0 · 2026-11-11

- 新增“整理走线”，适用于当前电路，确认后调整路径，保留端点、线色和备注，支持一次撤销
- 补码示例保存 61 根导线的固定路径，避开芯片外框，减少共线覆盖，电气连接和芯片位置保持不变
- 分离几何命中、DOM 帮助函数、芯片资料展示和 Toast 组件，删除旧模式样式、未使用函数和参数
- 芯片参数表逐项排列，补充设计注释，整理引脚查看和时序芯片移动、删除时的状态清理
- 说明弹窗直接使用 HTML 内容，不再由脚本按段落序号覆盖旧文案
- 整理操作使用蓝色“确认整理”，删除使用红色“确认删除”，修复悬停时文字与背景对比不足
- 构建时同步示例 JSON 和 Markdown 接线表，PDF 保持原样

## v1.1.1 · 2026-11-11

- 工具栏增加放置图标，再次点击同一型号或按 Esc 可以取消放置，只读时保持资料查看

- 重新构建离线运行文件，补充全部 23 种芯片直接点击插孔放置的交互测试

## v1.1.0 · 2026-11-11

- 按用户提供的芯片合集增加 16 种芯片，保留原有七种芯片的模型和原厂资料
- 新增 OC 输出、三态缓冲、译码器、选择器、比较器、七段译码器、D/JK 触发器、计数器和移位寄存器
- 选中节点后，你可以添加或移除弱上拉，测试 OC 输出与总线连接

- 器件库、实验列表和左栏整体分别滚动，输入输出按设置的位数显示
- 修正查看芯片时状态栏文字滞后的问题，统一移除提示和注释末尾句号

## v1.0.0 · 2026-11-10

- 项目命名为 SDU 面包板，英文名为 SDU-BreadBoard，工作区迁至 `D:\RJGC\SDU-BreadBoard`
- 根据山东大学计组实验面包板建立四块面包板、X/Y 母线和右侧电源地线
- 支持七种常用芯片，内置双符号位补码运算器和完整原厂引脚资料
- 新建独立实验时复用现有空白，允许保留多份已编辑实验；整理重复空白和完全相同的补码副本前保留备份
- 自动保存默认关闭，Ctrl+S 只保存当前实验。有未保存内容时，关闭或刷新页面会出现浏览器离开确认。你选择留在页面后，可以按 Ctrl+S 保存
- 右上角提供快捷删除，删除前弹窗确认。Ctrl 多选可以同时选择器件和导线
- 选择模式下可以拖动导线端点和转折点。重叠位置优先选择导线，再次点击可选择接口或芯片
- 普通滚轮上下移动，Ctrl+滚轮缩放。输入端模块上移，紧凑操作栏为画布留出更多空间
- 页面显示版本号和北京时间，备注支持 Markdown 编辑与预览
