# 版本记录

## 版本规则

小改动增加补丁号，例如 1.0.0 → 1.0.1；大改动增加次版本号，例如 1.0.1 → 1.1.0；大规模重构增加主版本号，例如 1.1.0 → 2.0.0。版本号以 `src/version.mjs` 和 `package.json` 为准

## v1.4.1 · 2026-11-11

- 搜索框的焦点边框包住图标和输入区，并与实验选择框对齐
- 移除“我的实验”中的“双符号位补码运算器”快捷入口，保留已有实验和示例文件
- 左侧“核对当前实验接线”替换为“诊断”，不再将任意实验与加法器示例比较
- 按芯片列出供电、输入、电平冲突、短路、OC上拉及离散时序状态，关电时也可发现电源轨短接
- 诊断不改变输入、接线或寄存器状态，支持只读模式，接线和输入变化后自动更新
- 标准示例比对移到开发测试中，保留示例回归覆盖

## v1.3.3 · 2026-11-11

- 修正 74LS160 并行载入非法 BCD 值后的恢复路径
- 修正 JK 未知状态的明确置位与复位、禁止计数和保持移位时的未知时钟处理
- 改善 74LS283 进位、74LS85 高位比较中的未知值传播
- 为 74LS20、74LS85、74LS112、74LS194 显示材料版与原厂 DIP 脚号差异，资料表区分 NC 和双向引脚
- 异步置位与清零同时有效时给出警告，增加全芯片供电、全部字形、同钟采样和计数器级联回归

## v1.3.2 · 2026-11-11
