# SDU 面包板使用说明

入口为根目录的 `index.html`，支持离线使用

你可以在左侧“我的实验”中新建空白实验，或切回之前保存的实验。每份实验都有自己的接线、输入状态和 Markdown 备注

实验列表支持方向键选择、回车确认和 Esc 取消，Home、End 分别定位首项与末项

## 当前功能

- 四块 59 列面包板，每列 A～E 相通，F～J 相通；第四块的输入与脉冲对应列跨沟槽接通，其他列的上下五孔组分开
- 每块面包板都有 X、Y 横向母线，按原图分为 1～17、19～41、43～59 三段；每六列中的第六列是母线空位。X、Y 及不同板块之间互不相通，也不自动接电源或地
- 最右侧外侧两列，从左到右固定为 GND 和 +5V；各列上下连通，各有 60 个等距插孔，首尾对齐第一块面包板 X 排和最后一块 Y 排
- 器件库收录了 23 种芯片，其中新增的 16 种依据用户提供的芯片合集实现，原有七种型号沿用了原实现
- 逐孔接线、空白处增加导线转折、12 种预设线色及任意自选颜色。预设颜色固定排成两行，每行六个
- 工具栏的走线选择框位于颜色选择区前面，打开页面默认使用“45°走线”，也可以切换为“自由走线”。45° 模式以横竖线为主，转角处使用短斜线，横纵各最多一个孔距，单段长度最多为根号二个孔距；角度随导线文件保存，旧版长斜线也按这个限制显示
- 引脚与节点电平检查、芯片放置与移动、导线删除、撤销和重做
- 板载 K0～K23、L0～L23，以及 P+、P− 手动完整脉冲
- 输入输出端口与面包板列网格对齐，每隔一列一个端口，上下模块外框与面包板等宽；所有 LED 均为已知高电平亮，X、Z 不点亮
- 输入输出板上没有接线孔，K、P 信号接第四块对应列的 A～J，L 信号只接最上块对应列的 A～E，常显细线表示板内连接
- 节点电平以字符显示：0 低电平、1 高电平、X 未知或冲突、Z 悬空，每个五孔组标注一次
- 你可以独立设置 1～24 位输入输出显示，各端口的意义由当前电路和备注确定
- 当你通过图钉固定芯片资料后，面板会持续显示其全部引脚信息，接线或切换标签时仍会保留。再次点击图钉可恢复跟随选择，切换实验或删除该芯片后会清除固定状态
- 普通滚轮上下移动画布；Ctrl＋滚轮以鼠标位置为中心缩放。控件、指示灯和面板有平滑过渡，仿真电平立即更新
- 电路备注支持 Markdown 编辑与安全预览，包括表格、代码、列表和链接；随文件保存，内置补码示例包含完整操作与端口说明
- 输入悬空、错误供电、多个输出相连、电源短接和不稳定反馈诊断；新错误用 Toast 提示
- 自动保存默认关闭。当你按 Ctrl+S 或点击保存图标后，程序只保存当前实验，其他实验各自保留未保存状态。JSON 用于导入导出，PNG 用于分享接线图片
- 项目预置了双符号位补码运算器，保留了两个符号位及六位反馈
- 左侧“整理走线”使用 libavoid 正交避障引擎，统一安排拐角和线间距，并避开芯片。起点、终点、线色和备注保持不变，支持撤销。无可用路径时保留原接线并提示原因
- 逐根连接插孔时也使用同一引擎，新线参考已有路径规划，已有导线不移动；你点击指定的中间转折点会作为必经点
- 引擎统一处理了导线间距，画布绘制、点击命中和文件保存共用了同一条路径
- 当你确认“整理走线”后，程序会在等待期间显示 Toast；完成或失败后，等待提示会自动关闭并显示结果
- 选择“45°走线”后，程序先生成横竖主路径，再将局部转角处理为短斜线。单段斜角横纵各最多一个孔距，避开芯片，相邻斜角之间保留直线
- 标题旁的“只读”开关保护接线、芯片、显示位数和备注，你仍可以调整输入、发脉冲、查看引脚和导出文件
- “诊断”覆盖了电源脚、输入悬空或未知、驱动冲突、短路、OC 上拉及离散时序状态，并依据当前接线逐片列出工作条件。加法器示例比对属于独立的开发测试
- 原有七种芯片使用 TI 引脚图，新增芯片使用文档中的引脚图和逻辑符号，你可以先查看图片，再核对实时电平和孔位

## 使用步骤

1. 打开示例后，将 K6 切到 0，再切回 1，完成清零
2. 设置五位补码输入，K0 是最低位，K4 是符号位；用 K5 选择加减
3. 发出一次完整 P− 脉冲后，读取输出，重复输入和发脉冲即可连续运算

当你在器件库选择芯片后，程序会显示资料并进入放置模式。芯片缺口朝左，跨接 E/F 沟槽；再次选择同一型号或按 Esc 可取消放置，只读模式下仅查看资料

每个孔只能插入一根导线或一个芯片脚，同组分支需要使用其他空孔。移动芯片后，导线仍留在原物理孔。新建电路的备注模板提供了功能、端口和实验步骤栏目

当你按住画布或外部的 P+、P− 按钮时，脉冲会保持有效电平，松开后恢复。P+ 在按下时产生上升沿，P− 在松开时产生上升沿。取消按压或窗口失去焦点后，脉冲也会恢复默认电平

测试 74LS03 时，选择输出节点后点击“为此节点添加上拉”。上拉是弱高电平，允许 OC 输出把节点拉低；直接接到 +5V 则会与低电平输出冲突

你可以在[示例接线说明](complement-wiring.md)中查看每根导线的端点、引脚对应关系和固定路径。导线通过两端插入的孔建立电气连接，途经其他插孔或交叉处时保持绝缘

快捷键：Esc 取消接线；Ctrl+Z 撤销；Ctrl+Shift+Z 重做；Delete 请求删除选中对象；Ctrl+S 保存当前实验。你可以按住 Ctrl 多选器件和导线，在选择模式下拖动导线端点或转折点

当你关闭或刷新含有未保存更改的页面时，浏览器会显示离开确认。选择留在页面后，可以按 Ctrl+S 保存当前实验；“备份全部实验”会导出整个列表

浏览器按页面地址管理本地数据。迁移项目文件时，请先在旧页面备份全部实验，再到新页面导入

旧版 K、L、P 接线端点导入时会转到对应列的空孔，GND、VCC 转到右侧电源轨空孔。转换会检查原有信号是否被额外连通，有冲突时停止导入并给出提示，原 JSON 文件不变

第四块的 K0～K23 对应第 49、47、…、3 列，P+ 对应第 53 列，P− 对应第 57 列。这些列的 A～E 与 F～J 通过固定细线接通，因此你可以在上下任一空孔取到同一信号。第 1、2 列、偶数列和其余未对应输入的列仍分开，X、Y 母线不参与桥接

## 模型边界

实验台采用了理想数字逻辑模型，用 0、1、X 和 Z 分别表示低电平、高电平、未知和无驱动。模型将悬空输入作为未知值处理，真实 TTL 悬空输入可能出现的上拉行为留给实物实验观察

74LS273 在上升沿保存数据，低电平可以异步清零。初次上电、断电重开、重新载入文件和结构撤销后，寄存器会进入未知状态，你需要通过清零接线重新初始化。实验文件保存了电路结构和按键状态，寄存器的易失数据会在重新加载时重置

P− 默认高电平，单次脉冲执行高→低→高；P+ 默认低电平，执行低→高→低。模型计算的是离散逻辑状态，传播时间、建立保持时间、按键抖动、电流、负载、电源波动和芯片损坏属于实物实验的观察范围。当你将多个推挽输出接到一起时，程序会报告接线问题，当前输出相同也适用这一规则

电路在传播轮次内未稳定时，输出显示为未知，诊断会提示你检查反馈连接。需要精确传播时延的实验适合使用时序仿真工具

诊断读取了当前输入和已有仿真结果，检查过程中会保留接线与脉冲状态。面板会显示清零、保持、等待时钟和电源关闭等状态，并提示时钟未知、异步控制冲突或寄存器尚未初始化的问题。你验收电路功能时，还需要逐项输入测试数据；实际电流、传播延迟和建立保持时间需要通过实物仪器或专门的时序工具测量

## 开发与验证

```powershell
npm install
npm run lint
npm test
npm run build
npm run test:ui
```

浏览器测试使用了开发依赖中的 Playwright 和本机安装的 Edge，在 Windows 开发环境中安装依赖后即可运行

逻辑测试覆盖了门电路真值和未知传播、74LS283 全部 512 种输入、完整补码运算器全部 4096 种输入组合、两组课程验收、上升沿和异步清零、断电、X/Y 分段连通、电源短接、端口网格对齐、通用模式、备注迁移及导入校验。浏览器测试覆盖了实际界面操作、Toast、Markdown 安全过滤、固定引脚信息、滚轮缩放、保存导入往返、图片导出与五种宽度布局

项目自有代码采用了普通命名函数、普通循环和中文说明。`vendor` 保存了第三方原始依赖，`application.js` 由构建程序生成。你修改功能时，请编辑 `src/` 中对应的源码，再重新构建

`src/geometry.mjs` 维护导线路径与命中，`src/routing.mjs` 负责自动整理，`src/dom.mjs` 提供页面节点帮助函数，`src/chip-reference-view.mjs` 复用芯片资料展示，`src/toast.mjs` 管理提示和计时。界面交互和可访问性仍由界面代码维护，样式和动效分别放在 `styles/` 与 `src/motion.mjs`

`npm run route:preset` 为示例重新生成固定路径，随后运行 `npm run build` 同步运行脚本、示例 JSON 和接线说明。路径测试保留优化前的独立示例作对照，逐项检查 61 根导线端点、线色和芯片位置不变，并核对路径不穿过芯片外框

## 上线

项目采用了纯静态页面，你可以将它部署到支持 HTTPS 的静态网站服务。执行 `npm run build` 后，按原有相对目录上传以下文件：

- `index.html`
- `application.js`
- `styles/app.css`
- `styles/tokens.css`
- `styles/select.css`
- `vendor/lucide.min.js`
- `vendor/lucide.LICENSE`
- `vendor/logic.LICENSE`
- `assets/reference-board.jpg`
- `assets/pinouts/`
- `assets/datasheets/`

实验数据保存在你的浏览器中，可以导出 JSON 来备份和分享。上线时上传运行文件和资料目录，`node_modules`、测试报告及个人实验文件留在本地。正式发布前，请在目标浏览器和实物实验板上完成对照验收

## 依赖和资料

三值逻辑计算复用了 DigitalJS 项目使用的 `3vl` 库，版本 1.0.1，许可证见 `vendor/logic.LICENSE`。界面图标使用了 Lucide，许可证见 `vendor/lucide.LICENSE`

走线使用了 `libavoid-js` 0.5.0-beta.5 的 libavoid WebAssembly 引擎，许可证见 `vendor/libavoid.LICENSE`，源代码和构建说明见[布线引擎说明](routing-engine.md)。运行脚本已内嵌了引擎

Markdown 预览使用了 Marked 解析文本，再由 DOMPurify 过滤脚本、图片、iframe、事件属性和危险协议链接。远程图片也会被过滤，备注上限为 50000 字符

全部七种芯片的引脚图均已对照 TI DIP 封装资料，保存在 `assets/pinouts/`；完整手册在 `assets/datasheets/`。来源及核对记录见 `docs/chip-references.md`
