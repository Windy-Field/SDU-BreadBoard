# SDU 面包板使用说明

你可以离线使用根目录的 `index.html`

你可以在左侧“我的实验”中新建空白实验，或切回之前保存的实验。每份实验都有自己的接线、输入状态和 Markdown 备注

实验列表支持方向键选择、回车确认和 Esc 取消，Home、End 分别定位首项与末项

## 当前功能

- 左下角的“显示逻辑电路图”按当前面包板接线生成逻辑门与芯片功能块，保留物理脚号、反馈线和分支网络。支持缩放、网络核对和 SVG 导出，操作不改变原电路，详细内容见[逻辑图说明](logic-diagram.md)
- 模拟板包含四块 59 列面包板，每列 A～E 相通，F～J 相通；第四块中输入与脉冲对应列跨沟槽接通，其余上下五孔组分别连通
- 每块板的 X、Y 母线按原图分为 1～17、19～41、43～59 三段，每六列留出一格空位。母线各段和板块分别连通，电源与地需单独接线
- 最右侧外侧两列，从左到右固定为 GND 和 +5V；各列上下连通，各有 60 个等距插孔，首尾对齐第一块面包板 X 排和最后一块 Y 排
- 器件库收录了 23 种芯片，其中新增的 16 种依据用户提供的芯片合集实现，原有七种型号沿用了原实现
- 逐孔接线、空白处增加导线转折、12 种预设线色及任意自选颜色。预设颜色固定排成两行，每行六个
- 工具栏的走线选择框位于颜色选择区前面，打开页面默认使用“45°走线”，也可以切换为“自由走线”。45° 模式以横竖线为主，转角处使用短斜线，横纵各最多一个孔距，单段长度最多为根号二个孔距；角度随导线文件保存，旧版长斜线也按这个限制显示
- 引脚与节点电平检查、芯片放置与移动、导线删除、撤销和重做
- 板载 K0～K23、L0～L23，以及 P+、P− 手动完整脉冲
- 输入输出端口与面包板列网格对齐，每隔一列一个端口，上下模块外框与面包板等宽；所有 LED 均为已知高电平亮，X、Z 不点亮
- K、P 信号接第四块面包板对应列的 A～J，L 信号接最上块对应列的 A～E；常显细线标出了输入输出板与面包板的固定连接
- 节点电平以字符显示：0 为低电平，1 为高电平，X 为未知或冲突，Z 为悬空；每个五孔组标注一次
- 你可以独立设置 1～24 位输入输出显示，各端口的意义由当前电路和备注确定
- 图钉支持同时固定多份型号资料或芯片详情，各份资料独立滚动，可拖动分隔条或使用方向按钮调整上下空间。固定资料只在“检查”页显示，切换标签后保留固定状态；再次点击对应图钉只取消这一份。未固定资料在取消选择后关闭，切换实验会清除固定列表，删除芯片只清除该芯片的固定详情
- 普通滚轮上下移动画布；Ctrl＋滚轮以鼠标位置为中心缩放。控件、指示灯和面板有平滑过渡，仿真电平立即更新
- 电路备注支持 Markdown 编辑与安全预览，包括表格、代码、列表和链接；随文件保存，内置补码示例包含完整操作与端口说明
- “诊断”会检查悬空输入、错误供电、输出冲突、电源短接和不稳定反馈，发现问题时以 Toast 提示
- 自动保存默认关闭。当你按 Ctrl+S 或点击保存图标后，程序只保存当前实验，其他实验各自保留未保存状态。JSON 用于导入导出，PNG 用于分享接线图片
- 项目预置了双符号位补码运算器，其中保留两个符号位及六位反馈
- 左侧“整理走线”使用 libavoid 正交避障引擎，统一安排拐角和线间距，并避开芯片。起点、终点、线色和备注保持不变，支持撤销。无可用路径时保留原接线并提示原因
- 逐根连接插孔时也使用同一引擎，新线会参考已有路径规划，已有导线保持不动；手动指定的中间转折点会作为必经点
- 布线引擎生成的路径同时用于画布绘制、点击命中和实验文件保存
- 当你确认“整理走线”后，程序会在等待期间显示 Toast；完成或失败后，等待提示会自动关闭并显示结果
- 选择“45°走线”后，程序先生成横竖主路径，再将局部转角处理为短斜线。单段斜角横纵各最多一个孔距，避开芯片，相邻斜角之间保留直线
- 标题旁的“只读”开关会保护接线、芯片、显示位数和备注；输入、脉冲、引脚查看及文件导出仍可使用
- “诊断”覆盖了电源脚、输入悬空或未知、驱动冲突、短路、OC 上拉及离散时序状态，并依据当前接线逐片列出工作条件。加法器示例比对属于独立的开发测试
- 原有七种芯片使用 TI 引脚图，新增芯片使用文档中的引脚图和逻辑符号，你可以先查看图片，再核对实时电平和孔位

## 使用步骤

1. 打开示例后，将 K6 切到 0，再切回 1，完成清零
2. 设置五位补码输入，K0 是最低位，K4 是符号位；用 K5 选择加减
3. 发出一次完整 P− 脉冲后，读取输出，重复输入和发脉冲即可连续运算

当你在器件库选择芯片后，程序会显示资料并进入放置模式。芯片缺口朝左，跨接 E/F 沟槽；再次选择同一型号或按 Esc 可取消放置，只读模式下仅查看资料

每个孔连接一根导线或一个芯片脚，同组分支使用其他空孔。移动芯片后，导线仍接在原物理孔。新建电路的备注模板包含功能、端口和实验步骤栏目

当你按住画布或外部的 P+、P− 按钮时，脉冲会保持有效电平，松开后恢复。P+ 在按下时产生上升沿，P− 在松开时产生上升沿。取消按压或窗口失去焦点后，脉冲也会恢复默认电平

测试 74LS03 时，选择输出节点并点击“为此节点添加上拉”。弱上拉可使 OC 输出释放时呈高电平，输出拉低时仍可控制节点。将输出直接接至 +5V 会造成驱动冲突

你可以在[示例接线说明](complement-wiring.md)中查看每根导线的端点、引脚对应关系和固定路径。导线通过两端插入的孔建立电气连接，途经其他插孔或交叉处时保持绝缘

快捷键：Esc 取消接线，Ctrl+Z 撤销，Ctrl+Shift+Z 重做，Delete 删除选中对象前先确认，Ctrl+S 保存当前实验。按住 Ctrl 可多选器件和导线；选择模式支持拖动导线端点和转折点

页面存在未保存更改时，关闭或刷新会触发浏览器离开确认。选择留在页面后，可按 Ctrl+S 保存当前实验，或导出当前实验 JSON

浏览器按页面地址管理本地数据。迁移项目文件时，请在旧页面逐份导出需要保留的实验，再到新页面导入；已有的完整实验备份仍可导入

导入旧版实验时，K、L、P 端点会迁到对应列的空孔，GND、VCC 会迁到右侧电源轨空孔。程序会核对信号连通关系，发现冲突就停止导入并提示；原 JSON 文件保持不变

第四块的 K0～K23 对应第 49、47、…、3 列，P+ 对应第 53 列，P− 对应第 57 列。这些列的 A～E 与 F～J 通过固定细线接通，因此你可以在上下任一空孔取到同一信号。第 1、2 列、偶数列和其余未对应输入的列仍分开，X、Y 母线不参与桥接

## 模型边界

实验台使用理想数字逻辑模型，以 0、1、X、Z 分别表示低电平、高电平、未知和无驱动；悬空输入按未知值计算。模型不包含真实 TTL 输入的上拉特性

74LS273 在上升沿保存数据，低电平可异步清零。初次上电、断电重开、重新载入文件或撤销电路结构后，寄存器状态为未知，需再次清零。实验文件保存电路结构和按键状态，重新加载时寄存器数据会重置

P− 默认高电平，单次脉冲执行高→低→高；P+ 默认低电平，执行低→高→低。模型计算离散逻辑状态。传播时间、建立保持时间、按键抖动、电流、负载、电源波动和芯片损坏需通过实物实验观察。多个推挽输出接在一起时，程序会报告接线问题，即使当前输出相同也一样

电路在传播轮次内未稳定时，输出显示为未知，诊断会提示检查反馈连接。需测量精确传播时延时，可使用时序仿真工具

诊断读取当前输入和仿真结果，检查时会保留接线与脉冲状态。面板显示清零、保持、等待时钟和电源关闭等状态，也会提示时钟未知、异步控制冲突或寄存器未初始化。功能验收需逐项输入测试数据；实际电流、传播延迟和建立保持时间可用实物仪器或时序工具测量

## 开发与验证

```powershell
npm install
npm run lint
npm test
npm run build
npm run test:ui
```

浏览器测试使用开发依赖 Playwright 和本机 Edge。Windows 开发环境安装依赖后，可运行这些测试

逻辑测试覆盖了门电路真值和未知传播、74LS283 全部 512 种输入、完整补码运算器全部 4096 种输入组合、两组课程验收、上升沿和异步清零、断电、X/Y 分段连通、电源短接、端口网格对齐、通用模式、备注迁移及导入校验。浏览器测试覆盖了实际界面操作、Toast、Markdown 安全过滤、固定引脚信息、滚轮缩放、保存导入往返、图片导出与五种宽度布局

项目代码使用普通命名函数、循环和中文说明。`vendor` 保存第三方依赖，`application.js` 由构建程序生成。修改功能时，请编辑 `src/` 中对应源码，再重新构建

`src/geometry.mjs` 负责导线路径与命中，`src/routing.mjs` 负责布线，`src/dom.mjs` 提供页面节点函数，`src/chip-reference-view.mjs` 展示芯片资料，`src/toast.mjs` 管理提示和计时。界面交互与可访问性由界面代码维护，样式和动效分别位于 `styles/` 和 `src/motion.mjs`

运行 `npm run route:preset` 可为示例重新生成固定路径，再运行 `npm run build` 更新运行脚本、示例 JSON 和接线说明。路径测试会将 61 根导线与原始示例逐项比较，核对端点、线色和芯片位置，并检查路径是否穿过芯片外框

## 上线

项目是纯静态页面，可部署到支持 HTTPS 的静态网站服务。运行 `npm run build` 后，按原有相对目录上传以下文件：

- `index.html`
- `application.js`
- `styles/app.css`
- `styles/tokens.css`
- `styles/select.css`
- `vendor/lucide.min.js`
- `vendor/lucide.LICENSE`
- `vendor/logic.LICENSE`
- `assets/reference-board.jpg`
- `assets/pinouts/`
- `assets/datasheets/`

实验数据保存在浏览器中，可导出 JSON 备份和分享。上线时上传运行文件和资料目录，`node_modules`、测试报告及个人实验文件留在本地。发布前需在目标浏览器和实物实验板上完成对照验收

## 依赖和资料

三值逻辑计算使用 DigitalJS 项目的 `3vl` 库，版本 1.0.1，许可证见 `vendor/logic.LICENSE`。界面图标使用 Lucide，许可证见 `vendor/lucide.LICENSE`

走线使用 `libavoid-js` 0.5.0-beta.5 的 libavoid WebAssembly 引擎，许可证见 `vendor/libavoid.LICENSE`，源代码和构建说明见[布线引擎说明](routing-engine.md)。运行脚本内嵌了引擎

Markdown 预览使用 Marked 解析文本，并由 DOMPurify 过滤脚本、图片、iframe、事件属性、危险协议链接和远程图片。备注上限为 50000 字符

七种原有芯片的引脚图均已对照 TI DIP 封装资料，保存在 `assets/pinouts/`；完整手册位于 `assets/datasheets/`。来源及核对记录见 `docs/chip-references.md`
