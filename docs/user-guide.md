# SDU 面包板使用说明

项目位于 `D:\RJGC\SDU-BreadBoard`。你可以双击根目录的 `index.html` 离线使用

你可以在左侧“我的实验”中新建空白实验，或切回之前保存的实验。每份实验都有自己的接线、输入状态和 Markdown 备注

实验下拉列表会在页面顶层展开，长名称自动换行，当前实验带勾选标记。你可以用方向键选择、回车确认、Esc 取消，Home 和 End 分别定位首项与末项。芯片位置中的板块选择使用相同样式

选中芯片后点击资料右上角的图钉，信息会固定显示，查看其他芯片、导线、备注或器件库资料时仍保留。再次点击图钉取消固定，恢复跟随选择。切换实验或删除该芯片会清除固定状态

## 当前功能

- 四块 59 列面包板，每列 A～E 相通，F～J 相通；第四块的输入与脉冲对应列跨沟槽接通，其他列的上下五孔组分开
- 每块面包板都有 X、Y 横向母线，按原图分为 1～17、19～41、43～59 三段；每六列中的第六列是母线空位。X、Y 及不同板块之间互不相通，也不自动接电源或地
- 最右侧外侧两列，从左到右固定为 GND 和 +5V；各列上下连通，各有 60 个等距插孔，首尾对齐第一块面包板 X 排和最后一块 Y 排
- 器件库包含 23 种芯片，其中 16 种依据用户提供的芯片合集新增，原有七种型号保留原实现
- 逐孔接线、空白处增加导线转折、12 种预设线色及任意自选颜色。预设颜色固定排成两行，每行六个
- 引脚与节点电平检查、芯片放置与移动、导线删除、撤销和重做
- 板载 K0～K23、L0～L23，以及 P+、P− 手动完整脉冲
- 输入输出端口与面包板列网格对齐，每隔一列一个端口，上下模块外框与面包板等宽；所有 LED 均为已知高电平亮，X、Z 不点亮
- 输入输出板上没有接线孔，K、P 信号接第四块对应列的 A～J，L 信号只接最上块对应列的 A～E，常显细线表示板内连接
- 节点电平以字符显示：0 低电平、1 高电平、X 未知或冲突、Z 悬空，每个五孔组标注一次
- 你可以独立设置 1～24 位输入输出显示，各端口的意义由当前电路和备注确定
- 选中芯片后在固定面板常显全部引脚信息，继续接线或切换备注、导线标签不会清空；可手动取消固定
- 普通滚轮上下移动画布；Ctrl＋滚轮以鼠标位置为中心缩放。控件、指示灯和面板有平滑过渡，仿真电平立即更新
- 电路备注支持 Markdown 编辑与安全预览，包括表格、代码、列表和链接；随文件保存，内置补码示例包含完整操作与端口说明
- 输入悬空、错误供电、多个输出相连、电源短接和不稳定反馈诊断；新错误用 Toast 提示
- 自动保存默认关闭。你按 Ctrl+S 或点击保存图标时，只保存当前实验；其他实验各自保留未保存状态。JSON 用于导入导出，PNG 用于分享接线图片
- 预置双符号位补码运算器，保留两个符号位及六位反馈
- 左侧“整理走线”可为当前电路调整路径，绕开芯片并减少重叠，确认后替换手动转折点，保留端点、线色和备注，支持撤销。无可用路径时保留原接线并提示原因
- 标题旁的“只读”开关保护接线、芯片、显示位数和备注，你仍可以调整输入、发脉冲、查看引脚和导出文件
- “诊断”适用于任意电路，检查电源脚、输入悬空或未知、驱动冲突、短路、OC 上拉及离散时序状态，并逐片列出当前工作条件，不与加法器示例比对
- 原有七种芯片使用 TI 引脚图，新增芯片使用文档中的引脚图和逻辑符号，你可以先查看图片，再核对实时电平和孔位

## 使用步骤

1. 打开示例，将 K6 切到 0，再切回 1，完成清零
2. 设置五位补码输入，K0 是最低位，K4 是符号位
3. 用 K5 选择加减，发出一次 P− 脉冲后观察输出
4. 点击“新建空白实验”创建独立实验，原实验留在列表中。点击器件库中的芯片后，你可以查看资料，同时自动进入放置模式；再点击面包板即可放置，芯片缺口朝左并跨 E/F 沟槽。再次点击同一型号或按 Esc 可以取消放置，只读时只查看资料
5. 接线模式选择起点和终点；点击空白增加转折点。每个孔只允许插入一根导线或一个芯片脚，同组分支需要使用其他空孔
6. 检查模式选择芯片，可看脚号、脚名、电平和孔位。移动芯片后导线仍留在原物理孔
7. 直接滚动鼠标滚轮上下查看，按住 Ctrl 再滚动时缩放。工具栏也有放大、缩小和适应宽度按钮
8. 打开右侧“备注”，使用编辑按钮填写 Markdown，再切到预览。新建通用电路提供说明模板，输入和输出的端口意义由设计者填写

你按住画布或外部的 P+、P− 按钮时，脉冲保持有效电平；松开后恢复。P+ 按下产生上升沿，P− 松开产生上升沿，按钮取消或窗口失去焦点也会恢复默认电平

测试 74LS03 时，选择输出节点后点击“为此节点添加上拉”。上拉是弱高电平，允许 OC 输出把节点拉低；直接接到 +5V 则会与低电平输出冲突

器件库列表与“我的实验”各自滚动，左侧栏不再整体滚动，底部的对照图和备份入口保持可见

补码示例的逐线端点、引脚对应关系和固定路径见[示例接线说明](complement-wiring.md)。交叉处没有接点，导线只有两端插入的孔参与电气连接

快捷键：Esc 取消接线；Ctrl+Z 撤销；Ctrl+Shift+Z 重做；Delete 请求删除选中对象；Ctrl+S 保存当前实验。你可以按住 Ctrl 多选器件和导线，在选择模式下拖动导线端点或转折点

关闭或刷新页面时，浏览器会对未保存更改显示离开确认。你选择留在页面后，可以按 Ctrl+S 保存当前实验；“备份全部实验”会导出整个列表

迁移前的浏览器数据若没有出现在新路径下，你可以在旧页面备份全部实验，再在新页面导入。浏览器按页面地址管理本地数据，项目文件迁移与浏览器实验数据分别保存

旧版 K、L、P 接线端点导入时会转到对应列的空孔，GND、VCC 转到右侧电源轨空孔。转换会检查原有信号是否被额外连通，有冲突时停止导入并给出提示，原 JSON 文件不变

第四块的 K0～K23 对应第 49、47、…、3 列，P+ 对应第 53 列，P− 对应第 57 列。这些列的 A～E 与 F～J 通过固定细线接通，因此你可以在上下任一空孔取到同一信号。第 1、2 列、偶数列和其余未对应输入的列仍分开，X、Y 母线不参与桥接

## 模型边界

实验台采用理想数字逻辑模型，支持 0、1、X 未知、Z 无驱动。悬空输入按未知处理；真实 TTL 输入可能表现出的上拉不参与计算

74LS273 在上升沿保存，清零低有效且不依赖时钟。初次上电、断电重开、重新载入文件和结构撤销后寄存器状态为未知，需要实际清零。保存文件只保存结构和按键，不保存易失寄存器状态

P− 默认高电平，单次脉冲执行高→低→高；P+ 默认低电平，执行低→高→低。仿真不模拟传播时间、建立保持时间、按键抖动、电流、负载、电源波动和芯片损坏。多个推挽输出接在一起，即便当前输出相同，也会报告接线问题

电路在传播轮次内未稳定时，输出显示为未知，诊断会提示你检查反馈连接。需要精确传播时延的实验适合使用时序仿真工具

诊断不会发出脉冲或改变电路。清零、保持、等待时钟和电源关闭会作为状态显示；时钟未知、异步控制冲突或寄存器尚未初始化会给出提示。诊断基于当前输入和已有仿真结果，不代表对全部输入组合的功能验收，也不测量实际电流、传播延迟或建立保持时间

## 开发与验证

```powershell
npm install
npm run lint
npm test
npm run build
npm run test:ui
```

浏览器测试使用项目开发依赖中的 Playwright，通过已安装的 Edge 运行。你执行 `npm install` 后即可在 Windows 开发环境中运行测试

逻辑验证包括门电路真值和未知传播、74LS283 全部 512 种输入、完整补码运算器全部 4096 种输入组合、两组课程验收、上升沿和异步清零、断电、X/Y 分段连通、电源短接、端口网格对齐、通用模式、备注迁移及导入校验。浏览器验证包括实际界面操作、Toast、Markdown 安全过滤、固定引脚信息、滚轮缩放、保存导入往返、图片导出与五种宽度布局

自有代码保持普通命名函数、普通循环和中文说明。`vendor` 中保留第三方原始依赖，`application.js` 为构建产物，不手工编辑

`src/geometry.mjs` 维护导线路径与命中，`src/routing.mjs` 负责自动整理，`src/dom.mjs` 提供页面节点帮助函数，`src/chip-reference-view.mjs` 复用芯片资料展示，`src/toast.mjs` 管理提示和计时。界面交互和可访问性仍由界面代码维护，样式和动效分别放在 `styles/` 与 `src/motion.mjs`

`npm run route:preset` 为示例重新生成固定路径，随后运行 `npm run build` 同步运行脚本、示例 JSON 和接线说明。路径测试保留优化前的独立示例作对照，逐项检查 61 根导线端点、线色和芯片位置不变，并核对路径不穿过芯片外框

## 上线

这是纯静态应用，可以部署到支持 HTTPS 的静态网站服务。执行 `npm run build` 后，将以下文件保持相对目录上传：

- `index.html`
- `application.js`
- `styles/app.css`
- `styles/tokens.css`
- `styles/select.css`
- `vendor/lucide.min.js`
- `vendor/lucide.LICENSE`
- `vendor/logic.LICENSE`
- `assets/reference-board.jpg`
- `assets/pinouts/`
- `assets/datasheets/`

实验数据保存在你的浏览器中，JSON 导出文件适合备份和分享。上线时只上传运行文件和资料目录，`node_modules`、测试报告及个人实验文件留在本地。正式发布前，你需要在目标浏览器和实物实验板上完成对照验收

## 依赖和资料

三值逻辑计算复用 DigitalJS 项目使用的 `3vl` 库，版本 1.0.1，许可证见 `vendor/logic.LICENSE`。图标使用 Lucide，许可证见 `vendor/lucide.LICENSE`

走线整理复用 `javascript-astar` 0.4.1 进行网格寻路，许可证见 `vendor/astar.LICENSE`。依赖已打入运行脚本，离线使用不需要安装或下载

Markdown 使用 Marked 解析、DOMPurify 清理。预览不接受脚本、图片、iframe、事件属性或危险协议链接，不加载远程图片。备注上限为 50000 字符

全部七种芯片的引脚图均已对照 TI DIP 封装资料，保存在 `assets/pinouts/`；完整手册在 `assets/datasheets/`。来源及核对记录见 `docs/chip-references.md`
